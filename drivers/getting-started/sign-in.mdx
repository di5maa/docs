title: "Signing in"
---

If you've already registered on Local Pass, use the Sign In screen to access your account. You don't need a password — Local Pass verifies your identity by sending a code to your phone each time you log in.

## How to Sign In

<Steps>
  <Step title="Open the Sign In screen">
    On the Local Pass welcome screen, tap **Sign In**. If you're on the registration screen, tap the back arrow at the top left to return to the welcome screen, then choose Sign In.
  </Step>
  <Step title="Enter your phone number">
    Tap the **Phone Number** field and type the mobile number linked to your account. The field formats your number automatically — it should look like `+1 (604) 555-1234`.
  </Step>
  <Step title="Tap Sign In">
    Tap the **Sign In** button. Local Pass checks whether your number matches an existing driver account.

    - **Match found** → an SMS with a 6-digit verification code is sent to your phone. You'll be taken to the [Verify Code screen](/verifying-your-phone).
    - **No match found** → you'll see the message **Account does not exist**. See the troubleshooting section below.
  </Step>
</Steps>

## Troubleshooting Sign In Issues

<AccordionGroup>
  <Accordion title="I see 'Account does not exist'">
    This means Local Pass couldn't find a driver account linked to the number you entered. A few things to check:

    - Make sure you're entering the same number you used when you registered
    - Confirm the number includes the country code — it must start with **\+1**
    - If you registered recently and still get this message, wait a few minutes and try again

    If you're certain the number is correct but still can't sign in, contact Local Pass support.
  </Accordion>

  <Accordion title="I never received the SMS code">
    After tapping Sign In successfully, you should receive a text within a few seconds. If it doesn't arrive:

    - Check that you have mobile signal or a data connection
    - Check that your number is not blocking texts from unknown senders
    - Wait up to 60 seconds — codes can be delayed on some networks
    - Go back and try entering your number again to request a new code

    See the [Verify Code](/verifying-your-phone) page for more help with the OTP step.
  </Accordion>

  <Accordion title="I don't have an account yet">
    Tap **Register as a driver** at the bottom of the Sign In screen. This takes you through the full [account creation](/creating-your-account) process.
  </Accordion>
</AccordionGroup>

## What Happens Next

Once your number is verified, you'll be taken straight to your **Driver Profile**. If your profile setup was never completed, you'll be redirected to the [Driver Onboarding](/completing-your-driver-profile) wizard to finish it first.
