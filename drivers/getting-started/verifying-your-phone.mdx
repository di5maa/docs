title: "Phone (OTP)"
---

Every time you sign in or register on Local Pass, a **6-digit verification code** is sent to your phone by SMS. This screen is where you enter that code to confirm you own the number. The process is the same whether you're signing in or registering for the first time.

## What OTP Means

OTP stands for **One-Time Password**. It's a single-use code that expires quickly and can only be used once. It replaces the need for a traditional password and ensures only the person holding the phone can access the account.

## Entering Your Code

<Steps>
  <Step title="Check your text messages">
    Open your phone's Messages app. Look for a new text from Local Pass. It should arrive within a few seconds of the previous screen. The message will contain a 6-digit number.
  </Step>
  <Step title="Tap the first box and enter the code">
    On the verification screen you'll see six input boxes. Tap the first one — your keyboard opens automatically. Type your 6-digit code. The cursor moves to the next box automatically as you type each digit.

    <Tip>
      On most phones, iOS and Android will detect the SMS code automatically and offer to fill it in for you with a prompt above your keyboard. Tap **\[the code\]** to paste it instantly without needing to type it manually.
    </Tip>
  </Step>
  <Step title="Tap Verify Code">
    Once all six digits are filled in, tap the **Verify Code** button in the bottom right. Local Pass will confirm the code and log you in.

    - **Signing in** → you'll be taken to your Driver Profile home screen
    - **Registering** → a new driver account is created and you'll be taken to the [Driver Onboarding](/completing-your-driver-profile) wizard
  </Step>
</Steps>

## If Something Goes Wrong

<AccordionGroup>
  <Accordion title="My code isn't working">
    OTP codes expire within a short window (typically a few minutes). If the code is rejected:

    - Make sure you're entering the most recent code — if you requested more than one, only the latest one is valid
    - Check you haven't misread a digit (6 and 8, or 1 and 7, are common mix-ups)
    - Tap the back arrow to return to the phone number screen and request a fresh code
  </Accordion>

  <Accordion title="I never received the code">
    If no text arrives after 30–60 seconds:

    - Check your mobile signal — you need at least one bar to receive SMS
    - Make sure your number is not set to block texts from unknown numbers
    - Some carriers have a short delay — wait up to 90 seconds before requesting again
    - Tap the back arrow and re-enter your phone number to send a new code
  </Accordion>

  <Accordion title="I accidentally went back — do I need a new code?">
    Yes. Tapping the back arrow takes you to the phone number screen. You'll need to enter your number again and a new code will be sent. Your previous code is no longer valid once a new one is issued.
  </Accordion>
</AccordionGroup>

<Warning>
  Never share your OTP code with anyone. Local Pass support staff will never ask for your verification code. If someone asks for it, do not provide it.
</Warning>
