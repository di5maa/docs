---
title: "Editing an Existing Promotion"
description: "If you need to update the terms, duration, or details of a campaign, you can edit an existing promotion. To access the editor, navigate to your Promotions list and select the promotion you wish to modify."
---

Editing uses the exact same screen as creating a new one — see [Add new promotion](/restaurants/promotions-manager/add-new-promotion) for what every field does. This page covers what's different about editing.

<Note>
  **You can't change the promotion's Type** (e.g., turning a "Buy X Get Y" into an "Amount off Order") once it's created. Create a new promotion instead if you need a different type.
</Note>

## What You Can Change

Every field from Add new promotion is editable, including:

- **Title and Description**
- **The Amount section** — discount type/value, and for Buy X Get Y or Discount on Products, the selected products/categories (tap **Browse products or categories** to change the selection, or remove a single item with the **X** next to it)
- **Minimum Requirements**
- **Active Dates and scheduling**
- **Feature on store** and **Limit to one use per customer**

<Warning>
  On Buy X Get Y and Discount on Products, you still can't save with an empty required side — add at least one product or category, or switch it to "Any product in the store."
</Warning>

## Saving Changes

- **Save Draft:** Saves your changes and takes the promotion offline immediately. Use this to pull a live promotion down without deleting it.
- **Update:** Saves your changes and puts the promotion live immediately (once the Start Date has passed).

<Note>
  **There's no separate "pause" action.** Saving as Draft is how you take a promotion offline temporarily. Deleting it removes it permanently and can't be undone.
</Note>

## Troubleshooting

| Issue | What's happening |
| :-- | :-- |
| **My promotion shows "Inactive" in a list, but I know I published it** | Open it in Edit and check the Summary panel's status badge directly — that's the source of truth. If it says Active there, customers can already redeem it, even if a list view elsewhere hasn't caught up yet. |
